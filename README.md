# 🌐 Homepage — HTML/CSS/JS

## 📖 Overview
This project is a *responsive homepage* built with plain HTML, CSS, and a small amount of JavaScript.  
It’s designed as a clean and modern landing page that can be used as a personal portfolio, a project showcase, or a starter template for websites.

---

## ⚙ Features
- Responsive layout (works on desktop and mobile)  
- Clean modern design with gradient backgrounds  
- Simple navigation bar with mobile toggle menu  
- Hero section with headline, description, and call-to-action buttons  
- Preview/mockup area for screenshots or demos  
- About section with description of the template  
- Projects list to showcase featured work  
- Contact section with personal info and links  
- Footer with auto-updating year  

---

## 📂 Project Structure

├── index.html     # Main HTML file ├── style.css      # CSS (can be separate or inline) ├── script.js      # JavaScript (optional, for menu/year) └── README.md      # Project documentation

---

## 🚀 Usage
1. Clone or download the repository.  
2. Open index.html in any browser.  
3. Edit the content (hero text, projects, contact info) to make it your own.

## 🧠 Key Concepts
- *HTML5* semantic structure (header, main, footer, sections)  
- *CSS3* for responsive grid/flexbox layout and styling  
- *JavaScript* for small dynamic features (mobile menu, auto year)  
- No external frameworks (pure HTML/CSS/JS) → fast and lightweight
