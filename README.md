🎲 Scrabble

📖 Overview

Scrabble is a CS50 problem set project that simulates a word game between two players.
Each player enters a word, and the program calculates scores based on letter values, then determines the winner.


---

⚙ Features

✅ Takes input words from two players

✅ Calculates score for each word based on Scrabble letter values

✅ Handles uppercase and lowercase letters

✅ Declares the winner or if it’s a tie



---

📂 Project Structure

├── scrabble.c    # Main program logic  
└── Makefile      # Compilation instructions


---

🚀 Usage

1. Compile the program



make scrabble

2. Run the game



./scrabble

3. Enter words for Player 1 and Player 2
The program will calculate scores and announce the winner.




---

📊 Sample Output

Player 1: hello
Player 2: world

Player 2 wins!

Player 1: game
Player 2: play

Tie!


---

🛠 Requirements

C compiler (clang or gcc)

CS50 Library (provided by the course)
